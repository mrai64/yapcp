## How add a Federation

To add a new Federation, there must be a request from a user whose organization is planning a competition sponsored by that Federation. This is not because the platform refuses to accept new federations, but because it creates a virtuous cycle of information exchange regarding: the federation itself, how it organizes the contests it sponsors, and whether it requires specific data during the registration phase. All of this information is easy to obtain when the organization is preparing to launch a new contest.
