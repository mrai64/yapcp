## Modify a record to Federation More (fields) table

Organizing photography contests, sponsored by various federations, requires
in some cases form with “additional” information beyond the minimum
required by all contests, even those that are not sponsored.
We have chosen to create a database of the additional fields requested by the Federation, and this form handles these form definition data. The unique identifier is
the `field_name`, which cannot be changed.
