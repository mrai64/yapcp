# Add a Federation Section

---

## Definition

Federations are the national and international associations that
represent photographer, and fix in regulation docs how must be
managed contests implemented and done.

To help Organization to build contest for a Federation we provide
some info about section n themes aligned to these regulation docs.

## Add a Federation Section

We appeal them federation section to distinguish from section in contest
named contest sections. That's all.

&nbsp;

Start from Federation List admin view
![_](/docs/federation_sections/add_img01.png)

&nbsp;

Choose the Federation, than the Add link
![_](/docs/federation_sections/add_img02.png)

&nbsp;

The empty form.  
Field required are:

> <!-- not for Larecipe index -->
- a code, assigned by federation and based on docs
  and or on report that must be produced by organization
- an international english short name, or the
  official name from federation docs.
- a Synopsis, or extract of definition frm official docs.
  These is a textarea can be enlarged in height
- Min and max works, i.e. for portfolio should be
  a min greater than zero
- Min and max px size
- Max Byte size, for 5MB write 5000000 no comma no separators
- check if Monochrome is required
- check if RAW are required to prove authenticity of work
  usually on when theme is Nature or Traditional Photo
- check if in a section can be assigned only a prize per author
