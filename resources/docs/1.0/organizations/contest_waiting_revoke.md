## About that function

Some checks on the images submitted by entrants to competitions can be carried out automatically, but all images must be viewed by a human to ensure they comply with the competition’s theme. Some images reuire to be placed in a waiting list until the recognized problem was solved. When its solved, simply the image must be removed from waiting set.
