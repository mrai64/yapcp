# Stato avanzamento lavori / State of Art

Le schede tecniche usano un [template](dev/template.md)
che va seguito. Spesso viene fatto scrivere a diverse
"intelligenze artificiali", quali a titolo di esempio: 
Gemini, Copilot, Antigravity, ChatGpt, altre.

---

Invece di lavorare su due binari paralleli, uso il project di github
come deposito delle cose da fare, per ogni questione una scheda.  
Si usano id:aaaa-mm-gg.nn per sequenziare l'ordine di creazione delle schede
e un flag A B C D E per dare priorità, e una funzione feat, docs, fix, refactor ecc.
