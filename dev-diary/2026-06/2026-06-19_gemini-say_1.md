# Gemini say del 19 giugno 2026

## Domanda 1 

Siamo al 19 giugno, uso vsc e credevo di avere già sistemato tutto riguardo a Gemini Code Assistant, ma ho visto l messaggio "this client is no longer supported". Ho disinstallato Gemini Code Assist.

Estensione ufficiale evitando fake ?

## Risposta 1

Il messaggio che hai visualizzato è corretto e non dipende da un'estensione "fake".

### Cosa sta succedendo

A partire dal **18 giugno 2026**, Google ha ufficialmente interrotto il supporto per le estensioni di "Gemini Code Assist" dedicate ai piani individuali (inclusi i profili Google AI Pro e Ultra). Questo fa parte di una transizione strategica verso una nuova piattaforma di sviluppo chiamata **Antigravity**.

### Come procedere ora

Se sei un utente individuale, il vecchio client di Gemini Code Assist non funzionerà più. Google ha unificato i propri strumenti in questa nuova piattaforma.

Per continuare ad avere assistenza basata su AI in VS Code con strumenti ufficiali Google, devi seguire queste indicazioni:

1. **Migrazione ad Antigravity:** Google sta spingendo gli utenti a migrare verso **Antigravity** e utilizzare il relativo **Antigravity CLI**. È questa la tecnologia che sta sostituendo le vecchie estensioni.
2. **Verifica la documentazione ufficiale:** Ti consiglio di consultare il portale [cloud.google.com/gemini](https://cloud.google.com/gemini) per verificare lo stato del tuo piano e le istruzioni aggiornate su come configurare l'accesso alla nuova piattaforma, poiché le vecchie guide (e i video tutorial che potresti trovare online) potrebbero non essere più validi.
3. **Estensione Google Cloud Code:** Se utilizzi Google Cloud per il lavoro (aziendale), l'estensione ufficiale rimane **"Google Cloud Code"** (pubblicata da `Google Cloud`). Tuttavia, anche per questa, assicurati di aver aggiornato all'ultima versione disponibile tramite il Marketplace di VS Code, poiché l'integrazione con le funzioni di assistenza è in costante evoluzione.

**In sintesi:** Non reinstallare la vecchia estensione "Gemini Code Assist" perché il servizio di backend è stato disattivato per i piani individuali. La strada corretta è verificare l'accesso a **Antigravity** tramite il tuo account Google Cloud o la dashboard dedicata di Gemini per sviluppatori.

Progetto personale

## Risposta 2

È un momento di transizione importante per gli sviluppatori che usano l'ecosistema Google. Come hai notato, dal **18 giugno 2026**, le vecchie estensioni "Gemini Code Assist" per utenti individuali non sono più attive.

Per i tuoi progetti personali, hai essenzialmente due strade percorribili, a seconda di come preferisci lavorare:

### 1. La soluzione "nativa" di Google: Antigravity

Google sta convogliando tutta la sua tecnologia di sviluppo su **Antigravity**. Non è più una semplice estensione di VS Code, ma una piattaforma (e un CLI) pensata per gestire agenti AI che lavorano sul tuo codice.

* **Cosa fare:** Se vuoi restare nel solco ufficiale di Google, dovrai migrare al sistema **Antigravity CLI** e, se preferisci un'interfaccia IDE completa, scaricare **Antigravity IDE** (che è basato su VS Code ma ottimizzato per l'integrazione con i loro nuovi agenti).
* **Pro:** Integrazione perfetta, accesso alle ultime capacità di ragionamento agentico di Google.
* **Contro:** Richiede di cambiare workflow e abituarsi a un nuovo ambiente (anche se molto simile a VS Code).

### 2. La soluzione flessibile: VS Code + Estensione di terze parti (Cline)

Molti sviluppatori che usano VS Code "puro" e vogliono solo usare Gemini come motore AI stanno migrando verso estensioni che permettono di usare la **API Key di Gemini** direttamente in VS Code.

* **Come configurarlo:**
1. Vai su [Google AI Studio](https://aistudio.google.com/) e genera una **API Key** gratuita per il tuo account.
2. Installa l'estensione **Cline** (sviluppata da Saoud Rizwan, è molto popolare perché gestisce bene il contesto del progetto) dal marketplace di VS Code.
3. Nelle impostazioni di Cline, seleziona "Google Gemini" come provider e incolla la tua API Key.


* **Pro:** Mantieni il tuo VS Code esattamente com'è, senza dover installare altri software o cambiare IDE.
* **Contro:** Non è un prodotto "ufficiale Google" (è un'estensione di terze parti), ma è lo standard de facto attuale per chi vuole usare LLM diversi (o lo stesso Gemini) in VS Code in modo granulare.

---

### Cosa ti consiglio?

* **Se il tuo obiettivo è costruire prototipi rapidamente** delegando compiti complessi all'AI (es. "crea una web app da zero"), scarica **Antigravity IDE** dal sito ufficiale: è l'evoluzione su cui Google punterà tutto nei prossimi anni.
* **Se il tuo obiettivo è mantenere il tuo attuale VS Code** e avere solo un assistente intelligente che ti aiuti a scrivere codice, la combinazione **Cline + API Key di Gemini** è attualmente la scelta più rapida e meno invasiva per continuare a usare i modelli Gemini nel tuo editor preferito.
